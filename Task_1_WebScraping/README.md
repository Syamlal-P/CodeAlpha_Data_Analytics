# Task 1: Web Scraping – Fashion Product Dataset

## Objective
To collect fashion-related product data from a public e-commerce website using Python and BeautifulSoup.

## Tools & Libraries
- Python
- Requests
- BeautifulSoup
- Pandas

## Data Collected
- Product Name
- Category
- Price
- Product URL
- Image URL

## Workflow
1. Inspected HTML structure of the website
2. Identified product containers and attributes
3. Scraped relevant fashion data
4. Stored data in a structured CSV file

## Output
- fashion_products.csv (custom dataset for further analysis)

## Future Use
This dataset will be used for:
- Exploratory Data Analysis (Task 2)
- Data Visualization (Task 3)
- Sentiment Analysis (Task 4)
- Outfit Recommendation System
